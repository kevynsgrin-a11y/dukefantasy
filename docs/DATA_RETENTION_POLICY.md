# Data retention policy

Contract requirements always shorten these defaults.

| Class | Default |
|---|---|
| Deterministic fixtures | Indefinite, version controlled |
| Raw licensed payload | Transient or ≤7 days only when allowed |
| Normalized operational data | Contract maximum |
| Odds history | None without explicit historical rights |
| Public source documents | Lawful redacted copy or hash/citation |
| Availability/injury | Current season plus short operational window |
| Model outputs | Immutable issuance ledger if input rights permit |
| Provenance/correction/audit | Six years, subject to counsel/contract |
| Debug/security logs | 30 days; aggregates up to 13 months |
| Correction contact | 12 months after closure, then delete/anonymize |
| Backups | 35-day rolling maximum |
| Secrets | Never in records, analytics, payload archives, or logs |

Termination triggers a provider kill switch, deletion manifest, derived-data review, cache purge, and backup tombstone. Legal holds and privacy requests use separate controlled workflows.
