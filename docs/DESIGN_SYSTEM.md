# Design system — Night Game Ledger

The visual language is a Saturday-night operations desk: deep ink canvas, warm paper type, brass-gold scoreboard accent, restrained field green, sky-blue information, tabular numerals, and low-contrast yard-line/topographic texture. It does not imitate a broadcaster or school identity.

Core colors are `#07131F`, `#0D2030`, `#142B3D`, `#294255`, `#F5F2E9`, `#AAB9C5`, `#35B77C`, `#F1B84B`, `#65C7F2`, `#F59E5B`, and `#FF7066`. Headings use an editorial serif; interface uses Geist; scores use Geist Mono with tabular numerals.

Desktop uses a 12-column, 1480px maximum surface. Mobile prioritizes demo state, status, teams, task actions, and source context before charts/commercial modules. Tables either reflow or use labeled keyboard-focusable scroll regions. Every data component owns loading, empty, error, stale, partial, demo, provider-down, unknown, suspended, and geoblocked states.

Marks/photos require an asset registry with owner, source, rights, territory, expiry, crop, attribution, and social permission. Until then, original monograms and CSS atmosphere are the only assets.
