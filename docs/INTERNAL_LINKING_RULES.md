# Internal linking rules

Homepage links to all five utilities. Game links to teams, stadium, watch state, methodology, source, and corrections. Team links to schedule, portal, coach, and venue. Player links to programs and movement. Coach links to program and carousel. Stadium links to program and relevant games.

Links use crawlable anchors, descriptive text, no orphan eligible pages, and no invented destination. Redirects use 301 only for genuine aliases; unknown entities return 404; intentionally removed records use 410; useful historical pages remain 200.
