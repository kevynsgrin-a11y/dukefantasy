# Responsible-gaming controls

Clean Mode is default and separate from consent. Odds & DFS Mode requires deliberate adult/coarse-jurisdiction attestation, stores no exact DOB or precise location, shows a persistent mode label, and offers one-action exit.

Unknown/minor/restricted states receive no operator actions. Partner-approved jurisdiction eligibility must be server controlled and cannot rely only on IP. Estimates are informational, uncertain, and never guarantees. No loss-chasing language, urgency, personalized pressure, autoplay, or sensitive gambling analytics.

Current preview has no operator, affiliate, or wagering action. Jurisdiction-specific current helpline information must be sourced through an approved hotline provider before display.
