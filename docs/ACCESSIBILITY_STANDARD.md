# Accessibility standard

Target WCAG 2.2 AA.

Required: skip link; semantic header/nav/main/footer; logical headings; visible 2px focus; keyboard-complete controls; 44px preferred touch targets; labels and programmatic errors; status text beyond color; polite/throttled live regions; reduced motion; forced-color resilience; 320px reflow; 200% zoom and 400% text; no page overflow.

Charts expose text summaries and/or tables. Distribution, probability, mismatch, bracket, and sparkline visuals include accessible labels and adjacent values. Scrollable tables are named and keyboard focusable. Dialogs use modal semantics and obvious escape/cancel behavior. Time zones and demo/source states use plain language.
