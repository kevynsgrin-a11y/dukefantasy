# Competitor gap matrix

This is a hypothesis register, not a published comparison.

| Category | Hypothesized friction | Hub response | Evidence needed |
|---|---|---|---|
| Legacy broadcast portals | Utility under editorial/ad chrome | Above-fold slate, no autoplay, reserved ads below value | Dated mobile task audit |
| Recruiting networks | Basic movement behind access walls | Source-aware open fixture architecture | Rights and workflow audit |
| Odds-first products | Betting dominates default | Clean Mode with separate disclosure | Usability and preference study |
| Team/local sites | Logistics fragmented or stale | Maintained dated stadium guide | Sample policy freshness audit |
| Model tools | Opaque rankings and false precision | Model versions, uncertainty, accessible summaries | Methodology comparison |
| Social/community feeds | Rumor mixed with fact | Structured verification states and corrections | Claim trace study |

Named competitors may enter the research set only through a dated, reproducible audit. Protected layouts, naming, data, and content must not be imitated.
