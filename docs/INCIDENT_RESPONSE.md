# Incident response

Severity uses critical/high/medium/low based on user harm, data/identity exposure, integrity loss, unavailability, legal/rights impact, and exploitability.

For critical/high: contain with feature/provider/partner kill switch; preserve bounded evidence; rotate/revoke; quarantine unsafe data; notify security, data, editorial, operations, and counsel owners; patch and regression-test; deploy immutable rollback/fix; communicate accurately; complete a blameless review with owners and deadlines.
