# Backup and restore

The fixture preview is restored from Git and an immutable Sites version; no durable user database exists.

Future D1 uses automated backups/Time Travel, additive migrations, a 35-day maximum rolling window, environment isolation, quarterly restore drills, and deletion tombstone replay. Licensed documents/assets require R2 version/lifecycle controls. A restore is not complete until permissions, provenance, correction lineage, suppression lists, and retention deletions are verified.
