# Handoff protocol

Every handoff records mission, inputs, assumptions, decisions, deliverables with exact paths, evidence, risks, next owner, and one acceptance state: `PASS`, `PASS WITH CONDITIONS`, or `FAIL`.

Use `PASS` only when the assigned scope is complete and verified. Use `PASS WITH CONDITIONS` for bounded external dependencies or low-severity follow-up. Use `FAIL` for blocked acceptance criteria, unsupported claims, or unresolved critical/high findings.

The Managing Partner reconciles handoffs into the decision log, assumptions register, requirements traceability matrix, bug audit, and release-readiness report. Raw logs stay in artifacts; the main handoff contains concise evidence and references.
