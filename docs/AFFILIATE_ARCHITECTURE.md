# Affiliate architecture

No affiliate program is active. Future links resolve server-side from a stable offer ID through an HTTPS hostname/path allowlist. Records include partner, evidence/status, territory/jurisdiction, mode gate, expiry, disclosure, destination label, permitted tracking fields, health check, and kill switch.

Eligible links use `rel="sponsored nofollow noopener"`. Destination transparency is mandatory. Never invent best price/line, inventory, or official-partner status. Commercial order is independent of model/editorial order.
