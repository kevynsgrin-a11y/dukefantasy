# Social content playbook

Share templates cover games, playoff scenarios, portal movement, coaching economics, and stadium guides. Each draft includes canonical URL, UTM fields, source cutoff, fixture/production state, model version, accessible alt text, fact-check owner, and correction path.

No auto-posting, fabricated breaking news, unverified rumor, unlicensed mark/photo, or claim that a model is fact. Generated drafts require human review. Social cards use the same asset rights registry as pages.
