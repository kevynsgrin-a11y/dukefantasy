# Cost controls

Preview cost is bounded by static fixtures, one Worker application, no D1/R2, no provider calls during rendering, no third-party scripts, and capped simulation iterations.

Future controls: per-provider quota and circuit breaker, normalized snapshots, indexed pagination, request deduplication, versioned caches, queue backpressure, simulation rate/concurrency caps, email/ad/affiliate kill switches, bundle/CPU/subrequest budgets, daily spend alerts, and contract-aware refresh cadence.
