# Model card — hot-seat context

Version label: `hot-seat-2026.1.2-demo`

Current state: the 0–100 index and coverage values are authored fictional fixtures used to demonstrate an explanatory product surface. They are not firing probabilities and are not calculated from a trained model in this repository. Rumor is excluded.

The contract/buyout calculator is implemented separately and deterministically from remaining guaranteed compensation, mitigation applicability, and an estimated offset. The fixture contract records are not verified real-world terms.

Production activation requires documented performance/context features, verified administration and contract sources, cutoff controls, immutable snapshots, outcome labels that distinguish dismissal/for-cause/retirement/voluntary departure, and historical validation.
