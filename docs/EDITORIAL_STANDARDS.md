# Editorial standards

Every high-stakes factual page exposes an update time and source context. Structured data distinguishes confirmed fact, attributed report, model estimate, editorial interpretation, rumor, and fixture. Rumor never enters factual fields.

Copy must be original, plain, conference-neutral, and independent. Do not paraphrase paywalled reporting or use unlicensed marks/images. Explain model metrics in task language, disclose uncertainty, preserve frozen predictions, label sponsorship next to commercial actions, and correct material errors visibly.
